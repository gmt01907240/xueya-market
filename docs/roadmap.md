# 版本迭代规划

## 一、版本总览

| 版本 | 定位 | 目标 | 状态 |
| --- | --- | --- | --- |
| v1.0 | 比赛版 | 完整功能闭环 + 可体验演示 | 已完成 |
| v1.1 | 公测版 | 接入真实支付与对象存储，具备对外运营条件 | 规划中 |
| v1.5 | 单校运营版 | 跑通一所高校的供需与复购 | 规划中 |
| v2.0 | 多校 SaaS 版 | 院校隔离、机构客户与数据服务 | 规划中 |
| v3.0 | 智能化版本 | AI 定价、摘要、推荐与客服 | 远期 |

---

## 二、v1.0 比赛版（已完成）

**目标**：在一个可运行的作品中完整呈现产品价值与技术能力。

已交付：

- 三维分类筛选与本校专区
- 官方价格标准库、推荐定价、手动调价与后台校准
- 支付后自动交付、订单与卖家结算
- 前 10%—20% 试读与防复制保护
- 官方客服 + 卖家专属客服 + 工单状态追踪
- 实名与高校认证、交易权限拦截、后台审核
- 卖家中心、个人中心、求购广场、私信、举报、公告
- 管理后台九大模块
- 单文件离线演示 `demo.html`、Docker 部署与冒烟测试

---

## 三、v1.1 公测版（0—3 个月）

**目标**：从演示环境升级为可对外运营的正式服务。

| 优先级 | 事项 | 说明 |
| --- | --- | --- |
| P0 | 支付接入 | 微信 / 支付宝 / 银联，接入持牌机构分账，回调幂等与对账 |
| P0 | 对象存储 | 上传文件迁移至 OSS / COS，下载使用签名 URL，保留本地降级 |
| P0 | 安全加固 | 登录限流、验证码、密码找回、管理操作审计日志 |
| P0 | 内容风控 | 上传关键词与文件类型检测、重复资料指纹、侵权快速下架 |
| P1 | 通知体系 | 邮件 / 短信 / 站内信，工单与订单状态通知 |
| P1 | 数据分析 | 埋点、漏斗、留存与 GMV 看板 |
| P1 | 移动端优化 | PWA、移动端下单与试读体验 |
| P2 | 卖家工具 | 批量上传、资料包、销售报表导出 |

验收标准：

- 真实支付可完成下单、回调、分账与退款。
- 文件存储与下载不依赖本地磁盘。
- 管理操作可追溯，敏感信息脱敏展示。

---

## 四、v1.5 单校运营版（3—9 个月）

**目标**：在一所高校验证供需密度、复购与口碑。

| 方向 | 事项 |
| --- | --- |
| 认证 | 对接学校身份库或教务系统（可选）、认证有效期与年审 |
| 供给 | 校园合伙人体系、院系 / 学生会官方资料库、资料包专题 |
| 需求 | 开学季与考试季专题、课程维度订阅、求购撮合 |
| 增长 | 邀请奖励、校园大使、社群运营、内容种草 |
| 商业化 | 卖家会员、置顶推广、院校专区品牌位 |
| 服务 | 客服 SLA、纠纷仲裁流程、退款自动化 |

验收标准：

- 单校月订单 ≥ 600，购买转化 ≥ 8%，30 日复购 ≥ 15%。
- 认证用户占注册用户 ≥ 60%。
- 投诉 24 小时响应率 100%。

---

## 五、v2.0 多校 SaaS 版（9—18 个月）

**目标**：从单一市场升级为可复制的校园内容基础设施。

| 模块 | 能力 |
| --- | --- |
| 多租户 | 院校维度隔离数据、配置、价格库与运营后台 |
| 机构账号 | 院系 / 学生会 / 教育机构独立空间与成员管理 |
| 私有资料库 | 内部资料共享、权限控制、访问审计 |
| 开放能力 | 认证接口、内容 API、数据看板嵌入 |
| 运营中台 | 跨校排行榜、活动配置、内容审核工作流 |
| 计费 | 机构年费、按席位 / 按存储 / 按调用量计费 |

验收标准：

- 新学校可在 1 天内完成开通与配置。
- 机构客户可独立管理成员、资料与数据。
- 平台级数据可按院校维度统计与结算。

## 六、v3.0 智能化版本（18 个月以上）

| 能力 | 说明 |
| --- | --- |
| AI 定价 | 基于成交数据、课程难度与时效动态建议价格 |
| AI 摘要 | 自动生成资料摘要、知识点标签与适用课程 |
| 智能推荐 | 按课程、考试时间与学习进度推荐资料 |
| AI 客服 | 基于工单知识库自动应答，复杂问题转人工 |
| 内容审核 | 多模态识别盗版教材、敏感信息与低质内容 |
| 学习闭环 | 资料 + 习题 + 复习计划组合，提升用户留存 |
