## 4. 账号与权限

- [ ] 注册：密码 8—72 位且含字母数字；弱密码被拒绝
- [ ] 邀请码开启时，无邀请码/错误邀请码/超次数均被拒绝
- [ ] 登录失败达到阈值返回 429，并带 `Retry-After`
- [ ] 未登录访问上传、订单、结算返回 401
- [ ] 普通用户访问 `/api/admin/*` 返回 403
- [ ] 配置 `ADMIN_IP_ALLOWLIST` 后，非白名单来源访问后台返回 403
- [ ] 未实名用户不能上传、购买、下载
- [ ] 他人订单、支付单、学习计划不可读取（越权 404）
- [ ] 伪造 `X-Forwarded-For` 不能绕过登录限流（未开 `TRUST_PROXY`）

---

## 5. 核心交易链路

按顺序执行一次完整闭环：

- [ ] 卖家注册 → 实名/高校认证 → 管理员审核通过
- [ ] 卖家上传 20MB 以内文件 → 机审 → 人工审核通过
- [ ] 买家注册 → 认证 → 浏览 → 下单 → 支付
- [ ] 支付回调验签通过，订单变为已完成
- [ ] 下载成功，文件内容与上传一致，非授权用户不可下载
- [ ] 卖家收益到账（扣除 10% 服务费）
- [ ] 生成 T+1 待结算账单；`SETTLEMENT_DELAY_HOURS=0` 时自动结算
- [ ] 买家申请退款 → 管理员通过 → 结算取消、收益扣回、支付单标记已退款
- [ ] 银行卡待支付订单可由管理员人工确认，重复确认幂等
- [ ] 重复支付回调不重复加收益、不重复生成结算

## 6. 上传与内容安全

- [ ] 扩展名白名单生效，`.exe`、`.js` 等被拒绝
- [ ] 超过 20MB 被拒绝，空文件被拒绝
- [ ] 伪造扩展名被拒绝：`fake.pdf` 内容为文本、`fake.docx` 非 ZIP
- [ ] 非 UTF-8 的 `.txt` 被拒绝，正常 UTF-8 中文文本可上传
- [ ] 违法违规内容提交返回 422，且资料不入库
- [ ] 疑似内容进入人工复核，不误杀正常内容
- [ ] 举报 → 后台处理 → 下架链路可用
- [ ] 预览禁止复制/右键/下载，试读比例在 10%—20%

---

## 7. 支付与结算安全

- [ ] 支付渠道仅微信/支付宝/银行卡，无充值、无提现入口
- [ ] 回调签名错误、时间戳超时、金额不一致、渠道不匹配均被拒绝
- [ ] 支付单与订单金额、渠道一致
- [ ] 结算金额 = 订单金额 − 10% 服务费
- [ ] 退款后结算状态为 cancelled，卖家余额扣回
- [ ] 后台对账汇总包含已支付、已退款、待结算、已结算
- [ ] 真实支付模式（如启用）完成 1 笔小额支付与 1 笔退款联调
