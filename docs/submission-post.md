## 二、一句话介绍

学涯集市用「院校 × 学科 × 老师」三维结构重组校园资料，让买家先试读再购买、卖家按官方标准库智能定价、平台以实名认证和担保交易守住信任。

## 三、灵感与痛点

【用自己的话描述一次真实经历，例如：期末前在十几个群里翻找复习资料，找到的版本残缺、价格随意，买完还没有售后。】

我们观察到三个问题：

1. 资料分散在群聊和网盘，检索只能靠关键词碰运气。
2. 买家看不到内容不敢买，卖家不知道定多少钱。
3. 交易发生在熟人之间靠信任，陌生人之间缺少保障。

于是我们做了学涯集市：把非标资料结构化，把交易流程标准化。

## 四、核心功能

### 1. 三维筛选与本校专区

按院校、学科、老师自由组合筛选；认证用户默认进入本校专区，也可以切换到其他高校。

【截图：资料市场三维筛选】

### 2. 官方价格标准库与推荐定价

平台维护院校公开资料形成的参考价，上传时按「院校 + 学科 + 类型」自动匹配，给出推荐价与可调区间；卖家可一键采用或手动调整，运营可在后台人工校准。

【截图：上传页推荐定价卡片】

### 3. 试读预览与自动交付

所有资料提供前 10%—20% 试读，禁止复制与下载；支付成功后系统立即开放完整文件，无需人工发放。

【截图：资料详情试读区】

### 4. 双通道客服

平台官方客服处理 bug、建议与投诉；买家也可以在资料详情页直接咨询卖家。工单支持状态追踪、回复提醒与未读角标。

【截图：客服中心与工单详情】

### 5. 实名与高校认证

选择院校、填写真实姓名与学号，管理员审核通过后才能买卖；未认证用户只能浏览。认证通过后自动进入本校专区，院校信息锁定。

【截图：实名认证页与后台审核】

### 6. 管理后台

概览、资料审核、认证审核、客服工单、价格标准库、用户、举报、财务、公告九大模块，覆盖平台运营全流程。

【截图：管理后台】

## 五、技术实现

- **零依赖**：不使用任何 npm 包与前端框架，`npm start` 即可运行，部署成本极低。
- **单文件数据库**：SQLite WAL 模式，启动时幂等建表与补列，旧库可直接升级。
- **安全**：HMAC Token、密码加盐哈希、路由级权限、服务端交易门禁、试读文本服务端截断。
- **一致性**：金额以「分」存储，下单、扣款、分账、写订单在同一事务内完成。
- **可体验**：除完整 Web 应用外，另提供单文件 `demo.html`，双击即可离线体验核心流程。
- **可验证**：`npm test` 覆盖健康检查、筛选、试读、定价、鉴权与后台接口共 20 项。

## 七、商业化思考

- **收入**：交易抽成 10% 为主，叠加置顶推广、卖家会员与机构 SaaS。
- **路径**：单校试点验证复购 → 区域高校联盟 → 全国多校 SaaS。
- **壁垒**：院校 × 学科 × 老师的内容结构、价格标准库数据资产、实名认证网络效应。
- **合规**：接入持牌支付不沉淀资金；实名信息最小化采集与加密存储；版权审核与侵权快下架。

详见项目内 `docs/business-plan.md`。
